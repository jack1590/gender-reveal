## 🔧 Soporte

### Si algo no funciona:

1. **Abre test.html** - Te dirá exactamente qué falla
2. **Revisa la consola** - Presiona F12 en el navegador
3. **Lee la documentación** - Cada archivo .md tiene soluciones
4. **Verifica los servicios**:
   - Firebase Console
   - EmailJS Dashboard

### Problemas Comunes:

**Video no carga:**
- Verifica que `video.mov` esté en la carpeta
- Considera convertir a .mp4

**Votos no funcionan:**
- Verifica Firebase Database esté creada
- Aplica las reglas correctas

**Emails no llegan:**
- Verifica EmailJS Dashboard
- Revisa spam
- Verifica límite de 200 emails/mes
