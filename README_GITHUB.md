# Gender Reveal 🎉

Beautiful, interactive gender reveal invitation page with real-time voting and RSVP functionality.

## ✨ Features

- 🎥 Video player with custom controls
- 🗳️ Real-time voting (Team Girl vs Team Boy)
- 🗺️ Interactive Google Maps integration
- 📝 RSVP form with email notifications
- ⏱️ Countdown timer to the event
- 🎨 Beautiful pastel design with animations
- 📱 Fully responsive (mobile, tablet, desktop)

## 🛠️ Built With

- HTML5
- TailwindCSS
- Firebase Realtime Database
- EmailJS
- Google Maps
